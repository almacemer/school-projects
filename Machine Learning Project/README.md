# Find Formula
This project explores how machine learning models can learn and predict a hidden mathematical formula from a set of input-output pairs. The goal is to train models that can discover patterns and generalize to new data points.

## Models Used
- Linear Regression
- Decision Tree Regressor
- Support Vector Regression (SVR)
Each model was trained and evaluated using Mean Squared Error (MSE) to compare performance.

## Technologies
- Python
- scikit-learn
- NumPy
- Matplotlib
